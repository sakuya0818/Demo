1.FFmpeg_rtsp

在Qt中使用FFmpeg连接摄像头进行拉流，需要摄像头支持rtsp拉流，输入摄像头的rtsp地址，即可进行实时拉流。

![image text](https://github.com/sakuya0818/Demo/blob/main/docs/img/ColorMap.png)
